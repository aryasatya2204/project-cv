Latar Belakang, Tujuan & Ruang Lingkup

Landasan masalah dan batasan eksperimen proyek

Latar Belakang

Pemilahan sampah secara manual membutuhkan waktu, ketelitian, serta pemahaman karakteristik material agar sampah daur ulang tidak tercampur. Pendekatan Computer Vision menggunakan Convolutional Neural Network (CNN) dengan Transfer Learning dimanfaatkan untuk mengekstraksi fitur visual dari bobot pralatih dan menyesuaikannya ke enam kategori sampah.

Rumusan Masalah

Bagaimana mengembangkan dan mengevaluasi model CNN berbasis transfer learning yang mampu mengklasifikasikan citra sampah ke dalam enam kategori pada dataset TrashNet?

Batasan Task

Multiclass Image Classification: Memprediksi satu label kelas per citra. Tidak mencakup object detection (lokasi bounding box) maupun image segmentation.

Tujuan Proyek

  1. 1 Mengembangkan model klasifikasi citra untuk mengenali enam kategori sampah pada dataset TrashNet.
  2. 2 Menerapkan transfer learning dengan model pralatih agar proses pelatihan berjalan lebih efisien.
  3. 3 Membandingkan performa model utama dengan model pembanding menggunakan accuracy, precision, recall, F1-score, dan confusion matrix.

Dataset TrashNet & Prapemrosesan

Sumber: Gary Thung & Mindy Yang (Stanford CS229) • 2.527 Citra JPEG

GitHub TrashNet ↗ Kaggle Dataset ↗

Distribusi Jumlah Gambar per Kelas

Total: 2.527 Citra

Catatan Ketimpangan Kelas: Kelas paper memiliki 594 gambar (23,5%), sedangkan kelas trash hanya 137 gambar (5,4%). Penanganan seperti class weighting atau augmentasi terarah akan dipertimbangkan berdasarkan hasil eksperimen.

Rencana Pembagian & Prapemrosesan

Train (70%) Val (15%) Test (15%)

Menggunakan stratified split agar proporsi 6 kelas terjaga di tiap subset.

  • • Resolusi Citra: Ukuran asli dataset hasil resize 512×384 diseragamkan menjadi 224×224 piksel dan dinormalisasi.
  • • Augmentasi Data Latih: Pembalikan horizontal (horizontal flip), rotasi sudut kecil, dan penyesuaian kecerahan (brightness).
  • • Validasi & Uji Murni: Data validasi dan data uji tidak diberikan augmentasi agar evaluasi mencerminkan performa nyata.

Arsitektur Model & Rencana Evaluasi

Perbandingan dua arsitektur CNN berbasis bobot pralatih ImageNet

Model Utama

MobileNetV2 (Pretrained ImageNet)

Dipilih sebagai arsitektur utama karena bobotnya relatif ringan, efisien untuk eksperimen klasifikasi citra, dan ideal untuk deployment inferensi cepat (seperti ONNX Web pada halaman ini). Bagian classifier head disesuaikan menghasilkan 6 keluaran kelas.

Model Pembanding

ResNet50 (Pretrained ImageNet)

Digunakan sebagai pembanding performa dengan arsitektur residual yang lebih dalam. Kedua model akan melalui proses fine-tuning pada dataset TrashNet dan dievaluasi secara menyeluruh per kelas menggunakan precision, recall, F1-score, dan confusion matrix.
